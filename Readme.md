## 📌 Project Overview

This project documents my hands-on experience using **Wazuh** for Security Operations Center (SOC) monitoring and **File Integrity Monitoring (FIM)**.

The objective of this lab was to connect a Windows endpoint to a Wazuh Manager, configure File Integrity Monitoring, generate file activities, and investigate the security alerts generated by Wazuh.

I used a **pre-built Wazuh virtual machine provided for the lab**, so I did not perform a fresh Wazuh installation. Instead, I focused on configuring the lab environment, connecting the Windows endpoint, configuring FIM, generating test events, and investigating the resulting alerts.

This practical exercise helped me understand how a SOC analyst can use Wazuh to monitor endpoints, detect suspicious changes, and investigate security events from a centralized dashboard.

---

# 🎯 Lab Objectives

The main objectives of this lab were to:

- Configure the lab network.
- Verify connectivity between the systems.
- Access the Wazuh Dashboard.
- Connect a Windows endpoint to Wazuh.
- Verify that the Windows Agent was active.
- Configure File Integrity Monitoring.
- Monitor a sensitive Windows directory.
- Detect file creation.
- Detect file modification.
- Detect file deletion.
- Investigate FIM alerts.
- Analyze file hash changes.
- Understand Wazuh rule severity.
- Examine MITRE ATT&CK mapping.
- Practice basic SOC alert triage.
